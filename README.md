- VPC  
- RDS / DynamoDB  
- IAM  
- S3

## Инструкция по запуску (опционально)
Если кто-то хочет повторить твой проект:  
1. Создать VPC и Subnets  
2. Развернуть EC2  
3. Настроить ALB и AutoScaling  
4. Подключить RDS  
5. Проверить доступ через браузер / Postman
